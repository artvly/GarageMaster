# Гараж Мастер

Десктопное приложение для автоматизации учёта заказ-нарядов, клиентов, автомобилей, работ и запчастей на станциях технического обслуживания (СТО) и в автомастерских.

Курсовая работа по дисциплине «Технология разработки программных систем», МГТУ им. Н.Э. Баумана, кафедра ИУ6.

## Стек

- **Язык:** C++17
- **Фреймворк:** Qt 6.5 — Qt Widgets, Qt SQL, Qt PrintSupport
- **БД:** SQLite через модуль Qt SQL (драйвер QSQLITE)
- **Сборка:** CMake + Ninja, компилятор MinGW 64-bit (или MSVC)
- **Тесты:** Qt Test

Подробнее — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Структура

```
src/core/    ядро: предметная область, БД и миграции, сервисы (без GUI)
src/app/     интерфейс на Qt Widgets
tests/       модульные тесты (Qt Test)
```

## Сборка

Открыть `CMakeLists.txt` в Qt Creator, выбрать набор *Desktop Qt 6.5.3 MinGW 64-bit*, собрать.

Или из командной строки:

```bat
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.5.3/mingw_64
cmake --build build
ctest --test-dir build --output-on-failure
```

При первом запуске создаётся пользователь `admin` с паролем `admin` и пометкой «сменить пароль при первом входе» (окно входа — в разработке).
