# Гараж мастер

Десктопное приложение для автоматизации учёта заказов, клиентов, автомобилей, работ и запчастей на станциях технического обслуживания (СТО) и в автомастерских.

Курсовая работа по дисциплине «Технология разработки программных систем», МГТУ им. Н.Э. Баумана, кафедра ИУ6.

## Стек

- **Язык:** C++17
- **UI:** Qt Widgets (основной интерфейс), Qt Quick/QML (отдельные экраны, например календарь загрузки постов)
- **БД:** SQLite через модуль Qt SQL (QSqlDatabase, драйвер QSQLITE)
- **Сборка:** CMake
- **Экспорт в Excel:** QXlsx

## Статус

Проект в начальной стадии разработки.
